# Screenshots

В эту папку следует добавить скриншоты актуальной версии AI QA Agent.

Рекомендуемые имена:

```text
01-main-ui.png
02-ui-artifacts.png
03-test-case-selection.png
04-automation-stack.png
05-api-mode.png
06-load-testing.png
07-generated-project.png
```

После добавления их можно встроить в корневой `README.md` так:

```markdown
## UI / Web mode

![UI mode](docs/screenshots/01-main-ui.png)

## Test case selection

![Test case selection](docs/screenshots/03-test-case-selection.png)
```

Не используйте скриншоты с:

- API keys;
- секретами;
- личными путями;
- production credentials;
- приватными endpoints;
- персональными данными.
