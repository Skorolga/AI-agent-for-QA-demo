# Test Plan — demo

## Цель

Проверить основной пользовательский путь:

```text
открытие сайта
→ навигация
→ открытие формы
→ заполнение
→ отправка
```

## Scope

- navigation;
- consultation form;
- validation;
- successful submission;
- server error handling;
- responsive layout;
- HTTPS.

## Out of scope

- CRM;
- administrative interface;
- операторская обработка заявки.

## Стратегия

- functional;
- positive;
- negative;
- boundary;
- integration;
- cross-browser;
- responsive;
- regression.

## Критерии завершения

- критические сценарии проверены;
- P0/P1 defects отсутствуют;
- требования покрыты test conditions и test cases;
- остаточные риски зафиксированы.
