# Test Cases — demo

## TC-001 — Открытие формы консультации
- Приоритет: P0
- Test Condition: TCND-001
- Предусловия: сайт открыт
- Шаги:
  1. Нажать «Получить консультацию».
- Ожидаемый результат:
  - открывается форма консультации;
  - отображаются обязательные поля.
- Automation: Recommended
- Automation reason: стабильный регрессионный сценарий с однозначным ожидаемым результатом.

## TC-004 — Валидный российский номер
- Приоритет: P1
- Test Condition: TCND-003
- Предусловия: форма открыта
- Тестовые данные: согласованный валидный номер
- Шаги:
  1. Заполнить имя.
  2. Ввести валидный телефон.
  3. Установить согласие.
  4. Отправить форму.
- Ожидаемый результат:
  - ошибка валидации телефона отсутствует.
- Automation: Recommended
- Automation reason: повторяемая проверка с детерминированным результатом.

## TC-008 — Ошибка сервера при отправке
- Приоритет: P0
- Test Condition: TCND-006
- Предусловия:
  - форма заполнена;
  - сервер обработки недоступен.
- Шаги:
  1. Отправить форму.
- Ожидаемый результат:
  - отображается сообщение об ошибке;
  - введённые данные сохраняются.
- Automation: Optional
- Automation reason: автоматизация полезна, но требует управляемого mock/stub или тестового backend.
