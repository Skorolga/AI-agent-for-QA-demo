# Анализ требований — demo

## Цель

Публичный адаптивный сайт должен:

- объяснять назначение сервиса;
- позволять пользователю изучить основные сценарии;
- предоставлять форму консультации.

## Ключевые требования

### Форма консультации

Поля:

- имя;
- телефон;
- согласие на обработку персональных данных.

### Валидация телефона

Телефон должен принимать корректный российский номер.

Не определены:

- допустимые форматы;
- наличие маски;
- нормализация `+7` / `8`;
- максимальная длина.

### Успешная отправка

После успешной отправки:

- отображается сообщение об успехе;
- повторная отправка после refresh не происходит.

## Риски

- дублирование заявки;
- потеря введённых данных при ошибке;
- расхождение правил валидации;
- ошибки адаптивной верстки.
