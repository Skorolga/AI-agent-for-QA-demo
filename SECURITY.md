# Security

Публичный demo-репозиторий не должен содержать:

- OpenAI API keys;
- access tokens;
- passwords;
- production endpoints с закрытым доступом;
- реальные персональные данные;
- приватные OpenAPI/Swagger-спецификации;
- внутренние корпоративные документы.

Перед публикацией рекомендуется проверить историю git на наличие секретов.

Для примеров используйте только synthetic/demo data.
